# لأعرفه — موقع رحلة قراءة الكتاب المقدس

أسرة القوي الأنبا موسى للجامعيين — كنيسة السيدة العذراء مريم بمدينة السادات

## الموقع فيه إيه
- **الدخول:** بالاسم ورقم الموبايل، مع أنيميشن اللوجو وهو بيطلع زي كتاب بيتفتح.
- **النهارده:**
  - قراءة اليوم، والخادم المسؤول.
  - زرار «قريت ✓» بيولّع شمعتك في شمعدان المجموعة.
  - كلمة اليوم وسؤال للتأمل، والأيام اللي فاتتك.
  - عداد لعيد الميلاد.
- **القراءة:** نص فاندايك بالتشكيل جوه الموقع، وتقدر تكبّر الخط، وتختار آية وتشاركها.
- **الرحلة:** جبل وعليه ٤٦ محطة، وكل مشترك بيطلع عليه حسب قرايته. وفيه ٩ شارات.
- **الخطة:** الأيام كلها، وتقدر تكمّل اللي فاتك من أي يوم.
- **الجماعة:** «آيات لمستنا» و«طلبات صلاة» بزرار «صلّيت».
- **أنا:** نسبة الرحلة، والأيام المتتالية، والشارات، وشهادة إتمام بتتحمّل صورة في الآخر.
- **لوحة الخدام (بكود):**
  - مين قرا ومين لأ، ومعاه زرار تذكير على واتساب.
  - كتابة كلمة اليوم والسؤال.
  - رسم بياني لعدد اللي قروا كل يوم.

## تشغيله على Firebase (مجاني)
1. ادخل على https://console.firebase.google.com واعمل مشروع جديد (مثلًا `la3rafo`).
2. **Build ← Authentication ← Get started**، وبعدين فعّل **Anonymous**.
3. **Build ← Firestore Database ← Create database** (اختار أقرب منطقة، مثلًا `europe-west`).
4. من **Project settings ← Your apps** اعمل Web app وانسخ الـ `firebaseConfig`، وحطه في `public/js/firebase-config.js` مكان `null`.
5. على الكمبيوتر:
   ```
   npm i -g firebase-tools
   firebase login
   firebase use --add        (اختار المشروع)
   firebase deploy
   ```
6. أول ما الموقع يشتغل، ادخل **أنا ← دخول الخدام ← أول مرة؟ حدد كود الخدام**، وحدد الكود وابعته لماركو وبيتر ومحب وبيشوي. لازم تعمل الخطوة دي قبل ما تنشر اللينك للمخدومين، عشان محدش غيرك يحدد الكود.

> لو فتحت تطبيق Claude على الكمبيوتر، أقدر أعمل الخطوات دي كلها بنفسي.

## ملاحظات
- طول ما `firebaseConfig = null` الموقع بيشتغل «وضع تجريبي»: البيانات على الجهاز بس، وفيه أسماء وهمية للتجربة.
- للتجربة على تاريخ معيّن ضيف للينك `?date=2026-12-14`.
- الدخول برقم الموبايل من غير كود SMS، يعني بيعتمد على الثقة، وده مناسب لمجموعة الأسرة. أرقام الموبايل بتظهر للخدام بس في لوحتهم.
- نص الكتاب المقدس: ترجمة فاندايك، وهي في الملكية العامة (public domain).
